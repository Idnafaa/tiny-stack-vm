A tiny stack VM for make.fun's stack ISA v1 (Node 22, stdlib only): executes each `program.bin` against `input.bin`, writes the bytes produced and the exit code.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
